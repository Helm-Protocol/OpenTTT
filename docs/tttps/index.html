TTTPS — Byzantine Audit API

PoC Proof-of-Time · Byzantine Detection · GRG Pipeline · Commercial Audit

Base URL

http://35.208.219.178:8080

Authentication

X-API-Key: tttps-dlr-poc-2026

Endpoints

MethodPathDescription
GET/healthService health check (no auth required)
POST/pot/generateGenerate Proof-of-Time token
POST/pot/verifyVerify token + Byzantine detection
GET/auditAudit report for a context window
GET/metricsPrometheus metrics

Health

curl http://35.208.219.178:8080/health

Generate PoT Token

curl -X POST http://35.208.219.178:8080/pot/generate \
  -H "X-API-Key: tttps-dlr-poc-2026" \
  -H "Content-Type: application/json" \
  -d '{"agent_id":"dlr-aipx-01","ctx_id":"dlr-poc"}'

Verify + Byzantine Detection

curl -X POST http://35.208.219.178:8080/pot/verify \
  -H "X-API-Key: tttps-dlr-poc-2026" \
  -H "Content-Type: application/json" \
  -d '{"token":"<token_from_generate>","agent_id":"dlr-aipx-01","ctx_id":"dlr-poc"}'

Audit Report

curl "http://35.208.219.178:8080/audit?ctx_id=dlr-poc&window=3600" \
  -H "X-API-Key: tttps-dlr-poc-2026"

Prometheus Metrics

curl http://35.208.219.178:8080/metrics
